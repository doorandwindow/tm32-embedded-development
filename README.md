# tm32-embedded-development
Develop, debug, review, and document STM32 firmware projects across HAL/LL, bare-metal, and RTOS codebases. Use when work involves STM32 peripherals, CubeMX-generated code, board bring-up, interrupt/DMA behavior, embedded build/flash, or resource-constrained firmware. Do not activate for generic C/C++ work without STM32 context.
